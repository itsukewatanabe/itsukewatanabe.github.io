# itsukewatanabe.github.io

Landing page for **Schachduell**, a small Android chess app for two phones on
different networks.

* `/schachduell/` — invite page: shows the code from `?c=CODE`, opens the app, offers the APK.
* `/Schachduell.apk` — the app itself (~62 kB, no dependencies).
* `/.well-known/assetlinks.json` — Digital Asset Links, so invite links open the app directly.

Source of the app: `/root/schachduell` on Leonid's build box.
