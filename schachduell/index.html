Wie es funktioniert

Die Partie läuft nicht über einen eigenen Server, sondern über den öffentlichen Relay-Dienst ntfy.sh — nur HTTPS, also durch jedes Mobilfunknetz, WLAN und VPN. Wer den Code hat, ist im Spiel; deshalb den Code nur an deinen Gegner schicken.
